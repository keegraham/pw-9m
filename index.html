15-minute work sample: GTM + Fullstory

Pinewake Exchange is a made-up listings marketplace. Build the tracking below in the GTM container you've been given, sending data to Fullstory. Fullstory is already on this page in simulated mode. Every call you make shows in the Fullstory call log at the bottom right, along with any errors Fullstory would give. The log is kept as you move between pages.

In GTM, click Preview and connect Tag Assistant to the start link your interviewer gave you.

Rules

  • Only change things in GTM. Don't edit this page's code.
  • Don't install the Fullstory snippet or template. Call the v2 browser API from your tags, for example FS('trackEvent', { name, properties }).
  • You can use the GTM and Fullstory docs. Please think out loud.
  • Find the data you need yourself, using Tag Assistant, the console and the page's elements.

Requirements (in order)

  1. Listing Viewed event on each listing page, with the listing ID and make, plus the price as a number (for example 24500). If a listing has no price, don't send a price.
  2. Lead Submitted event, only when the lead form is sent successfully, with the lead reference number and the listing ID.
  3. If you have time: a Phone Revealed event when a visitor reveals the dealer's phone on the main listing (not in the similar-listings cards), with the listing ID.

When time is up, your interviewer will give you a short click-path to run. Then click Copy log and paste it into the chat.

If you need to start over, reopen the start link.
